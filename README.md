# Briggs Tools for Revit - Releases

Installers for **Briggs Tools for Revit** (Revit 2022-2026) from Briggs Electric.

- Download the latest installer from [Releases](https://github.com/TheOtherCadGuy/BriggsTools-Releases/releases/latest).
- Installed copies check this repo automatically and offer updates when Revit closes.
- Each release includes the installer `.exe` and `latest.json` (version, download URL, SHA-256, release notes) used by the auto-updater.

This repository contains no source code. Releases are published by `scripts\New-BriggsRelease.ps1 -Publish`.
